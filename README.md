# Piggy's Adventure

Piggy's Adventure is a Roblox script designed to enhance the piggy model's behavior, including teleportation to the nearest item. This script is perfect for Roblox game developers looking to add interactive and dynamic elements to their games.

## Install

1. Download the script files from the GitHub repository.
2. Open your Roblox Studio.
3. Insert the Piggy model into your game.
4. Place the script files inside the Piggy model.

## Use

1. Ensure the Piggy model is properly set up in your Roblox game.
2. The script will automatically find the nearest item and teleport the piggy to it when triggered.
3. You can trigger the teleportation by connecting the script to a button press or other event in your game.
